# Examination Portal

A comprehensive examination portal for viewing and accessing exams from 1st year to 4th year, organized by units.

## Features

- Browse exams by year level (1st, 2nd, 3rd, 4th year)
- View all units for each year
- Access examination papers and resources
- Search and filter exams by subject/unit

```bash
npm install
npm start
```

## Year Levels

- **1st Year** - Foundation subjects and core units
- **2nd Year** - Intermediate level courses
- **3rd Year** - Advanced topics
- **4th Year** - Specialization and capstone projects
